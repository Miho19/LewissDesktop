  • Get shortcut

    Navigate to K:\Data\Process\Development\processing and copy the shortcut to your desktop

  • Select Project

    Use the navigation bar on the left to select a consultant

    A list of projects will be displayed and be selectable

    Select a project to view all windows split into tables by their blind type

    If a window is missing, it either has information missing from the treatment or is a roman/curtain

  • Select Blind

    Select the window(s) you wish to process

  • Edit Blind

    Some fields are editable

    Remote and channel are expected to be edited

  • Submit Blind

    Each blind type has a separate submit button as each blind type produces its own PDF

  • Edit Customer Details

    These values are displayed on the PDF

    The reference number is taken from Measure Pro but should be adjusted to match the current customer-invoice number you have

  • Edit Factory Instructions

    These instructions are for the factory

  • Edit Motor Accessories

    You must manually specify how many remotes you require for this order

  • Process Order

    You are able to go back and adjust details as needed

    Clicking process will create PDFs and worksheets on SharePoint

  • PDF Created

    Once the process has finished, the PDF will be opened locally as a temporary file

    You do not need to save this file

    This is simply to inspect the PDF for any errors

  • Output

    PDFs created will be available at K:\Data\Process\Wip\Pending

    These are named in the same manner as the current system
